## 2. Что есть в системе сейчас (стратегия ИИ)

- **Роль**: планировщик. Модель даёт `bias` (up/down/flat) **в каждом ответе**, уровень входа по ходу bias, стоп, цели, условие включения. Лимит ждёт цену до 72 ч, условие — до 12 ч.
- **Модель**: Qwen3.6-35B-A3B Q3_K_S на сервере (8 vCPU, 23 ГБ), в отдельном процессе; ~1.5 ток/с; вопрос ~5000 токенов; 9–12 мин на пару.
- **Данные (17 блоков)**: уровни с объёмом у каждого; ОИ (4ч/24ч/7д), фандинг с историей, лонг/шорт, премия; профиль объёма; поглощение; дельта по ленте с покрытием и по часам; стакан с реальным охватом; экстремумы вчера/недели/Азии; структура SMC 1ч; имбалансы; ордер-блоки/брейкеры; 4ч и день; ОИ по свечам; карта ликвидаций (оценка); ликвидации по факту (поток); BTC-ориентир; прошлые разборы пары; активность; ход за 4ч/24ч/7д и место в 30-дневном диапазоне.
- **Вход**: грамматика запрещает цены вне списка, неверную геометрию, стоп ближе минимума, цель ближе 2× минимума; код — факторы ≥4/5, R:R ≥2, EV>0 с реальными издержками, стоп под чужими стопами, условие против идеи; критик (та же модель) — на каждый план.
- **Выход**: стоп модели, цели 60/40 или 50/30/20, без безубытка, тайм-стоп 14 д. Позицию модель не ведёт.
- **Учёт**: `llm_calls.csv` (всё, включая сырой ответ), `refused.csv`, `llm_outcomes.csv` (ход цены через 1/4/12/24 ч, `bias`, R плана, `data_gap_bars`).

## 3. Отложено — и почему

| № | Причина |
|---|---|
| 2.1 Двухступенчатая система | На этом CPU «быстрой» модели нет: 8B шла с той же скоростью (1.8 ток/с) и ошибалась в геометрии. Дешёвый скрининг сделан кодом (1.1) — это и есть первая ступень без модели |
| 2.2 Независимый критик | Вторая модель другого семейства рядом с 15-гигабайтной не помещается по памяти и времени; облачная нарушает «всё на сервере». Зафиксировано как ограничение; пересмотр — по исходам (если критик подтверждает или отклоняет всё подряд) |
| 2.4 Калибровка `p` | Нужны 30–50 вердиктов с исходами; первые исходы — 20.09 |
| 2.5 Абляция блоков | То же: нужны исходы, чтобы было что сравнивать |
| 2.6 Самосогласованность | Материал есть (сырые ответы и разметки в журнале); прогон — ночью, ~1 ч машинного времени; сделаю после первых входов |
| 3.2 Стакан BTC глубже | Bybit отдаёт 500 уровней — это предел биржи. Стакан другой биржи — другой рынок; можно добавить как ориентир, но это отдельное решение |
| 3.3 Сверка карты ликвидаций | Через 7 дней истории потока (начат 19.09 14:56 UTC) |
| 3.5, 4.1–4.4 | Регулярные замеры, портфельная оптимизация, валидация факторов, бэктест ИИ, макро — отдельные работы, требуют данных или источников, которых нет |
