# Широкий перебор правил по индикатору LuxAlgo SMC — протокол, записан до расчёта, 27.10.2026

Владелец 27.10.2026: «как мы можем торговать по этому индикатору? давай найдём
выигрышные варианты — например, 1ч, вход от ордер-блока и до первой
ликвидности или имбаланса. Давай прогоним все возможные варианты».

Перебор тысяч вариантов на одной истории сам находит «прибыльные» — по
случаю. Защита — та же, что в PROTOCOL.md: отбор только на DEV, не более трёх
кандидатов на VAL со строгой приёмкой, HOLD — один раз и только с согласия
владельца (LUX_OPEN_HOLD=1). Разметка — lux.py, данные, издержки, исполнение
и периоды — как в PROTOCOL.md.

## Сетка (7 200 вариантов)

| измерение | значения |
|---|---|
| ТФ входа E | 15м, 1ч, 4ч |
| ТФ уровней Lv | тот же, что E, или старший (15м→1ч, 1ч→4ч, 4ч→1д) |
| направление | нет; тренд свинга E; внутренний тренд E; тренд свинга Lv; внутренний тренд Lv |
| блок | внутренний; свинговый |
| слом | любой; только BOS; только CHoCH |
| вход в блок | ближний край; середина блока |
| цель | L — ближайшая невынесенная ликвидность Lv; F — ближайший нетронутый имбаланс Lv; LF — ближайшее из двух; 2R; 3R |
| premium/discount E | без фильтра; лонг ниже середины крайнего диапазона, шорт — выше |
| срок заявки | 24 или 72 бара E |

Для L, F, LF уровень берётся не ближе 1R от входа; нет такого — сетапа нет.
Ликвидность — внутренние точки LuxAlgo (5 баров) на Lv, вынесена, когда
15-минутная свеча ушла за уровень. Имбаланс — по определению LuxAlgo на Lv,
перестаёт быть целью при касании ближнего края (как в PROTOCOL_MTF.md).
Направление «тренд Lv» при Lv = E совпадает с трендом E — это дубли, их
считают как есть.

Общее для всех: стоп за дальним краем блока на 0.1% цены, стоп ближе 0.25%
от входа — сетап не берётся; вся позиция закрывается на цели (без остатка);
удержание до 7 суток (у входа 4ч — 30 суток), потом закрытие по рынку; цель
раньше налива — заявка снимается; одна заявка/позиция на пару в варианте.

## Отбор на DEV (2021–2023)

Кандидат: ≥ 300 сделок, средний R > 0, t ≥ 2, и не меньше 60% соседей
(вариантов, отличающихся ровно одним измерением) со средним R ≥ 0.
На VAL идут три кандидата с наибольшим t. Нет кандидатов — на VAL никто.

## Приёмка на VAL (2024-01 … 2025-03)

Те же четыре условия, что в PROTOCOL.md: средний R > 0 с нижней границей 95%
бутстрэпа по дням > 0 (или ≥ 0 при ≥ 300 сделок и t > 2); при издержках ×1.5
средний R > 0; ≥ 55% пар (с ≥ 10 сделками) в плюсе; каждый год DEV и VAL не
хуже −0.05R. Затем HOLD — один прогон с согласия владельца.
